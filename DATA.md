# Data: where the AI learns from, and why

A language model learns by reading a large amount of text (see "training" in the [glossary](docs/GLOSSARY.md)). **What it reads shapes everything it can say, including its mistakes and biases.** So this project is strict about data.

The machine-readable list is [`data/sources.toml`](data/sources.toml); the test suite checks it against the rules below. **Status today (M0): nothing has been downloaded yet.** Every source below is a *candidate* until milestone M2 checks its licence and dataset ID against the source itself.

## The rules

1. **Openly licensed or public domain only.** Allowed: public domain, CC0, CC BY, CC BY-SA, Apache-2.0, MIT, BSD. For collections where each document has its own licence, we keep only the documents whose licence is on this list.
2. **Human-written only.** No text generated by AI models, including text written by the AI assistants that help build this project. Training on another AI's output would quietly copy that AI (breaking promise P3).
3. **Ethically sourced.** Licence permission is necessary but not always enough. **Indigenous-language data is used only with the consent and involvement of the community**, following the [CARE principles](https://www.gida-global.org/care) (Collective benefit, Authority to control, Responsibility, Ethics), even where a licence would allow it.
4. **Documented.** Every source is listed with its URL, licence, languages, intended use and known risks. Anyone can re-download and check it.
5. **No personal data on purpose.** We filter obvious personal information (emails, phone numbers) from training text. Public text can still mention real people.

| ID | What | Why |
|---|---|---|
| `fineweb` | FineWeb, C4, raw Common Crawl | Web pages copied without permission; the collection's licence does not cover the pages inside it |
| `the-pile` | The Pile (2020) | Contains Books3, copyrighted books used without permission |
| `tinystories` | TinyStories | Written by GPT-3.5/GPT-4 |
| `alpaca` | Alpaca, ShareGPT, UltraChat, Cosmopedia, OpenHermes and similar | Generated by existing AI models |
| `who-fao-nc` | WHO and FAO publications under CC BY-NC-SA 3.0 IGO | Non-commercial licence is incompatible with ours. The app may *link* to them. |
| `indigenous-without-consent` | Indigenous-language text gathered without community consent | CARE principles |

## Known risks and biases (honest list)

- **Language imbalance.** Open text is mostly English and European languages. The model will be much weaker in other languages at first. See [docs/LANGUAGES.md](docs/LANGUAGES.md) for the coverage table.
- **Historical bias.** Public-domain text is old by definition (often pre-1930). It contains colonial, racist, sexist and religious prejudices of its time. The evaluation suite (M4) measures bias, and results are published with each release.
- **Some AI-written text may slip in.** Wikipedia and volunteer datasets written after 2022 can contain text pasted from chatbots. We filter tell-tale phrases and record the residual risk (`ai_text_risk` in `sources.toml`).
- **Errors.** Sources contain mistakes; the model will learn some of them. This is one reason answers show their sources.

## Attribution

CC BY and CC BY-SA require credit to authors. Each release ships this file and `data/sources.toml`, naming every source and its licence. Whether model weights must carry their training data's licence is legally unsettled. We release weights under CC BY-SA 4.0 so that the share-alike terms of sources like Wikipedia are respected either way (see [docs/LICENSING.md](docs/LICENSING.md)).

## Adding a source

Open an issue with the source's URL, licence (with a link to where the licence is stated), languages, whether it is human-written, and any community whose consent should be sought. A maintainer adds it to `data/sources.toml` and this file in the same change.
